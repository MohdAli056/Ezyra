# Ezyra

Ezyra is a modern Mens Fashion web platform showcasing trending and seasonal collections. Built with pure HTML, CSS, and JavaScript, it offers a clean and responsive user interface for browsing fashion products. The platform features dynamic product filtering, curated collections, and trending items display to help users discover the latest in men's fashion.

## Features
- Responsive and modern UI design
- Dynamic product catalog with filtering options
- Detailed product views with HD image galleries
- Advanced search functionality
- Smart category organization
- Curated seasonal collections display
- Trending items showcase
- Mobile-first responsive design
- Smooth animations and transitions
- Performance optimized image loading


## Getting Started
### Prerequisites
- Any modern web browser
- Basic text editor (VS Code, Sublime Text, etc.)
- Git (for version control)

### Installation
1. Clone the repository
```bash
git clone https://github.com/MohdAli056/Ezyra.git
```

2. Navigate to the project directory
```bash
cd ezyra
```

3. Open the project
- Simply open the `index.html` file in your web browser
- Or use a local development server like Live Server in VS Code
